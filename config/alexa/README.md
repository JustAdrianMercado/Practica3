# Modelo de interacción de Alexa

[modelo-interaccion.es-US.json](modelo-interaccion.es-US.json) contiene el
modelo exportado para **Spanish (US), es-US**, nombre de invocación
**caja de enigmas**. Define seis intents propios, cinco integrados y 48 frases
propias. Vincular utiliza `numeroCaja` y `codigo`, ambos obligatorios, con
delegación automática del diálogo.

El modelo y las pruebas son responsabilidad de **Lucía Escobar**, conforme a la
[planificación original](../../docs/planificacion/04-lucia-skill-informe.md).
El diseño se explica en el [informe](../../INFORME.md#28-diseño-de-la-skill-de-alexa)
y las frases se conservan en la [matriz](../../docs/PLAN_PRUEBAS.md).
El archivo funcional JSON se mantiene sin cambios durante la reorganización.
